# Customer Service Interaction Directions

These are standalone interaction demos for review before production implementation.

1. `01-focus-thread.html` - focused thread with smart scroll and compact context rail.
2. `02-operator-workbench.html` - desktop operator workspace with persistent sessions and evidence panel.
3. `03-mobile-drawer.html` - mobile-first conversation flow with a session drawer.

Open any file directly in a browser. The demos use local state only and do not call the backend.
