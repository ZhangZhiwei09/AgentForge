AGENTFORGE / PROJECT NOTESREADME · 2026

把故障排查变成一条可检查的证据链

AgentForge 是一个面向企业场景的 AI 诊断工作台。它把问题、知识、工具调用和流程版本放到同一个可回放的工作面上。

PROJECT NOTE 01诊断不是一句答案，而是问题如何被定位、解释和复现。
01 / See the work

先看产品，再读架构

真正需要被展示的，是诊断结论背后的证据、检索质量和流程版本。

02 / What it holds

三个工作面

01

诊断对话

流式展示排查过程、知识引用和诊断结果，支持补充信息、工具调用与人工审批。

02

知识与质量

文档、分块、混合检索、命中测试与检索回归共同组成质量闭环。

03

Agent 流程

从草稿到发布、激活、试运行和运行记录，流程本身也能被管理。

03 / How it is arranged

项目地图

apps/customer-service 是诊断工作台，apps/data-admin 是管理端，apps/server-py 提供 API、Agent Runtime、知识库和 worker。

前端与共享组件继续使用 TypeScript；后端迁移到 Python，数据库迁移和管理脚本也由 Python 负责。

apps/ customer-service/ 诊断对话 data-admin/ 知识库与流程 server-py/ API / Runtime / worker packages/ sdk/ shared-types/ ui/ cui/
04 / Start here

从本地运行开始

安装与配置

准备 Node.js 20+、pnpm 9+、Python 3.12+、uv、Docker Desktop 和一个 OpenAI 兼容 API Key。

pnpm install
cd apps/server-py
uv sync --locked

启动工作台

配置 apps/server-py/.env 后启动基础设施、数据库和三项服务。

pnpm infra:up
pnpm db:migrate
pnpm db:check
pnpm dev

诊断前端 localhost:5173 · 管理端 localhost:5200 · API 文档 localhost:8000/docs
