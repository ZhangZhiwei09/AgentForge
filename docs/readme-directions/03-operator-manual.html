03

Runtime map

apps/customer-service 提供诊断工作台，apps/data-admin 提供知识库和流程管理，apps/server-py 提供 API、认证、知识库、Agent Runtime 和摄取 worker。

Node.js 负责前端开发、构建和浏览器测试；后端运行、数据库迁移和管理脚本使用 Python。
